# My Magical Day

A kawaii pixel-art daily planner inspired by the original Digital Typewriter / Receipt Printer concept.

## Features

- Editable events and to-do quests through a pixel-art modal with a bow ribbon.
- Planner name, mood charm, and receipt theme personalization.
- LocalStorage persistence, so changes stay after refresh.
- Click a task to mark it complete with sparkle effects.
- Double-click a task, or click an event, to edit/delete it.
- Progress stats and a cute animated receipt printer moment.
- Pastel Sanrio/Stardew/lo-fi inspired styling with floating pixel decorations.

Open `index.html` in a browser to use the app.
